Aprende Sobre Teoría del Color

Sistema HEX

Los códigos hexadecimales usan 6 dígitos (0-9, A-F) para representar colores en diseño web. Ejemplo: #RRGGBB

#FF5733

Sistema RGB

RGB significa Red, Green, Blue. Cada valor va de 0 a 255. Se usa en pantallas digitales.

rgb(255, 87, 51)

Sistema HSL

HSL significa Hue, Saturation, Lightness. Más intuitivo para ajustar colores. Hue: 0-360°, Sat: 0-100%, Light: 0-100%

hsl(11, 100%, 60%)
